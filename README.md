# 今日は鮒を走っちゃう？ ― 体内レーシング 鮒コース タイムアタック

鮒の体の中をレーシングカーで駆け抜ける、ネタ企画「体内レーシングゲーム」の小さな試作です。

**遊ぶ → https://konbu-love.github.io/funa-ta/**

## 遊び方

- 「鮒に入る」を押すとスタート。口から入って、咽頭歯ゾーン、腸を抜けて、出口（肛門）まで走ります。
- 管の内側なら壁も天井もどこでも走れます。コースアウトはありません。
- ◀ ▶ で壁に沿ってぐるっと回ります。画面を直接押すと、その方向へ動きます。
- ブーストは押している間だけ、ゲージが減ります。
- 咽頭歯の隙間を抜けて、うねる波に乗ると速くなります。
- 壁にぶつかると宿主のHPが減ります。ブースト中は2倍痛いです。
- HPがゼロになると宿主が悶絶して、自機も数秒動けなくなります。
- 出口に着くと、自機が水中へ排出されます。排出タイムと評価（ノーダメ賞〜人体への配慮なし）が出ます。

## 作りについて

- `index.html` 1枚だけで動きます（HTML + JavaScript、Canvasで疑似3D）。
- 鮒の顔のイラストは、画像として `index.html` に埋め込んであります。
- ベストタイムはブラウザの localStorage に保存されます。
- スマホ（縦画面）向けです。キーボードの ← → と スペースでも動きます。
